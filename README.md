## How to Run the Notebooks

The notebooks can be opened and executed using Google Colab without installing Python locally.

- Open the notebook file in this repository.
- Select Open in Colab if the option is available or download the .ipynb file and upload it to Google Colab.
- In Colab, select Runtime → Run all to execute the notebook cells and view the results.

For local execution, install Python and Jupyter Notebook. Install NumPy using:

``pip install numpy``
